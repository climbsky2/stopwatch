# stopwatch

심해를 배경으로 한 스탑워치 웹 페이지.

## 파일

- **deep-sea-stopwatch.html** — 밝은 청록빛 심해 배경(빛줄기·거품·플랑크톤·유영하는 물고기 8마리) 위에 황동 아날로그 다이버 워치 스타일 스탑워치. 초침 스윕, 분침, 디지털 판독, 랩 기록.
- **stopwatch.html** — 미니멀한 디지털 스탑워치.

## 사용법

`.html` 파일을 브라우저로 열면 됩니다.

- 시작 / 정지
- 실행 중 **랩** 기록, 정지 상태에서 **초기화**
- 단축키: `Space` = 시작/정지, `L` = 랩/초기화
